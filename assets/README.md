# Atlas AI — Assets

Source design assets for the Atlas AI brand mark. These are the originals;
the actual files the app serves (PWA icons, favicon) live under
`frontend/public/icons/` and are generated from the same design.

- `logo/atlas-logo-mark.svg` — the vector source for the logo (also used
  live in the UI via `frontend/src/components/common/Logo.tsx`).
- `icons/atlas-icon-512.png` — a rendered reference copy of the app icon.

## Design

The mark is a set of concentric contour lines around a summit/compass-needle
point — a topographic "you are here" motif that matches the product name.
Colors: ink (`#0E1116`) background, teal accent (`#2DD4A8` / `#1F8A70`), and
a small gold accent (`#D8B54C`) reserved for the summit marker only.
